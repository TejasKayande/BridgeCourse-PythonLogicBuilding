# TUI Calculator

A basic **Terminal User Interface (TUI) calculator** written in Python.

This program was created as a demonstration for a homework assignment and is intended to help students practice basic Python programming concepts.

## Features

The calculator currently supports:

* Addition
* Subtraction
* Multiplication
* Division
* Average
* Factorial
* Exit / Quit

## Running the Program

Make sure Python is installed, then run:

```bash
py main.py
```

## Homework / Further Practice

The program intentionally does **not** handle all possible errors.

Once you have learned exception handling, try improving the calculator by handling:

* Invalid number input
* Division by zero
* Empty input
* Other invalid user input

Feel free to modify the program, experiment with it, and add new functionality.
