# Memory Card Game

A simple memory card matching game written in **JavaScript** using HTML and CSS.

## About

The game contains 8 pairs of cards.

Cards are shuffled and hidden. The player must flip two cards at a time and find all matching pairs.

The game tracks:

* Number of moves
* Matched pairs
* Time
* Accuracy

The game ends when all 8 pairs have been found.

## Controls

| Input               | Action           |
| ------------------- | ---------------- |
| `Left Mouse Button` | Flip a card      |
| `Restart`           | Restart the game |

## Running the Game

Open `index.html` in a web browser.

No additional dependencies are required.
