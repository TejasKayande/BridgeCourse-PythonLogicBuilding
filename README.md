# Python Programs

This repository is intended for students attending the Bridge Course.

It contains a collection of Python programs that have been:

* Taught in the classroom
* Given as homework
* Included as additional practice to help strengthen your programming and problem-solving skills
* Interesting simulations that are fun to experiment with and reletively straight forward to code.

I encourage you to go through the code, understand how it works, and experiment with it yourself. Don't just copy and run the programs—try to understand the logic behind them and see if you can modify or improve them.

The goal is to use these programs as a starting point to build stronger programming fundamentals and develop your ability to think logically about problems.

**Happy Programming!**
